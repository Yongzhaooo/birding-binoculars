# 望远镜数据库

## 用途

个人自用的观鸟望远镜资料库，公开分享型号参数、参考入手价格与资料来源。网站地址为`wyj.cangming.fyi`，源码采用GPL-3.0-or-later。

## 功能

- 访客可以搜索型号，按品牌、倍率、口径、参考入手价和ED配置筛选，查看完整材料与光学参数。
- 参考入手价格是历史资料整理值，标注日期，不显示交易平台、卖家、商品链接或实时最低价。
- 下载只提供公开参数Excel，不含私人推荐首页或交易采集记录。
- 每款详情显示参数核验状态和来源。未知、待核、厂商声明与实际体验相互区分。
- 访客可以为指定型号提交本人实拍图片、参数修正和体验补充。图片投稿填写设备、拍摄条件和署名，确认拥有展示授权。所有投稿先待审。
- 审核员通过VPS命令行读取完整资料，批准后内容进入型号页和图库，拒绝的内容不会公开。
- 桌面和手机都可以浏览参数、打开详情和投稿，图片为空时明确显示尚无实拍。

## 当前边界

不提供购物交易、自动价格监控、自动发布投稿或社交账号系统。不把代码的GPL许可套用到他人的实拍照片或原始第三方资料。
